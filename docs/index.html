Integración Continua y Despliegue Colaborativo

La compilación del libro y la actualización de esta página web se coordinan automáticamente en la nube. Sigue esta guía para contribuir con tu equipo:

1. Descargar Últimos Aportes

Mantén tu repositorio actualizado con el trabajo de tus compañeros:

git pull origin main

2. Compilar tu Capítulo Aislado

Genera en segundos el PDF del capítulo específico en el que trabajas (ej. Cap. 2):

python scripts/build.py --chapter 2

3. Subir Avances a GitHub

Guarda y publica tus oraciones editadas (regla de una oración por línea):

git add .
git commit -m "Aporta texto en Cap 2"
git push origin rama-cap2
